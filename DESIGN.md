# TEFA UHT Design Direction

- Identity: Teaching Factory for food technology, production, and industrial research.
- Personality: sharp, disciplined, technical, practical, institutional.
- Palette: preserve the existing navy, cream, green, and orange system.
- Typography: preserve Manrope for headings and DM Sans for body copy.
- Composition: industrial editorial layout, hard edges, measured asymmetry, visible process cues.
- Icons: Lucide icons only, used when they clarify an action or technical category.
- Images: existing verified assets first. Missing imagery uses an explicit dummy placeholder.
- Framework: Tailwind utility classes may support layout and states; shared CSS remains the source for the existing static site.
- Dial: ENERGY 2 / RHYTHM 2 / MOTION 1.

Decision reasons:
- Navy anchors the institutional and technical tone.
- Orange marks action and process emphasis without spreading across every element.
- Cream keeps long technical copy readable.
- Manrope gives headings structural weight; DM Sans keeps body text operational and legible.
- Hard corners and thin rules reinforce equipment, documentation, and production workflows.
- Motion stays limited to hover, focus, menu, and filter feedback so technical content remains stable.
