# Audit UI TEFA UHT

Mode: AFTER

## Temuan

1. **HIGH, R-24/R-26/R-35**: Navigasi memuat tautan mati ke `get-involved.html`, `collaboration.html`, `facility-visit.html`, dan `contact.html`. File tidak ada di root, sehingga header dan footer mengarah ke halaman 404.
   - Bukti: semua halaman utama memakai tautan tersebut.

2. **HIGH, R-25/R-32**: Fokus keyboard dihapus pada input dengan `outline: none` di `assets/styles.css:950`, tanpa pengganti outline yang cukup jelas untuk semua konteks.
   - Bukti: aturan fokus hanya mengubah border dan shadow.

3. **HIGH, R-27**: Form demo hanya memiliki validasi browser dan status sukses. Tidak ada state loading atau error aplikasi.
   - Bukti: `assets/main.js:28-39` langsung memvalidasi lalu menampilkan `.form-success`.

4. **HIGH, R-37**: Tidak ada `DESIGN.md` atau dokumen arah visual. Implementasi belum punya Design Read dan dials ENERGY/RHYTHM/MOTION.

5. **HIGH, permintaan eksplisit**: Styling masih memakai authored CSS besar di `assets/styles.css` dan class custom. Tidak ada Tailwind CLI, `package.json`, `tailwind.config.*`, `src/input.css`, atau output build Tailwind.
   - Bukti: semua halaman utama hanya memuat `assets/styles.css`.

6. **MEDIUM, R-33**: Inline CSS tersebar di banyak halaman. Ini membuat sistem styling sulit dikompilasi dan dipelihara sebagai satu sumber Tailwind.
   - Bukti: inline `style=` ditemukan di `about.html`, `event-orders.html`, `facilities.html`, `gallery.html`, `index.html`, `products.html`, dan `research-development.html`.

7. **MEDIUM, R-23/R-38**: `gallery.html` memakai lima gambar Unsplash sebagai stock image. Copy memang menandai gambar sebagai ilustratif, tetapi audit tetap meminta keputusan eksplisit: pertahankan sebagai placeholder berlabel atau ganti dengan aset fasilitas yang disetujui.

8. **MEDIUM, R-02**: Teks UI memakai karakter em dash (`—`) di beberapa halaman. Antislop melarang em dash pada copy yang ditulis agent.
   - Bukti: `index.html`, `about.html`, `facilities.html`, `event-orders.html`, `products.html`, `research-development.html`, `produk.html`, dan `kapasitas.html`.

9. **LOW, R-15/R-16**: Beberapa CTA generik masih muncul, termasuk `Explore`, `Discover`, dan `Learn`. Ganti hanya bila ada tujuan aksi yang lebih spesifik.

10. **LOW, R-11**: Tombol dan badge memakai radius pill secara luas (`border-radius: 999px`). Perlu dipisahkan menurut hierarki komponen, bukan dihapus seluruhnya.

## Cakupan verifikasi

- Pemeriksaan tautan lokal: 9 halaman HTML diperiksa; 7 halaman utama memiliki tautan ke file yang tidak ada.
- Pemeriksaan Tailwind: tidak ditemukan konfigurasi, dependency, atau entry CSS Tailwind.
- Pemeriksaan inline style: ditemukan di 7 halaman.
- Belum ada perubahan source selain file audit ini.

Pilih nomor temuan untuk diperbaiki. Temuan yang tidak dipilih tidak akan disentuh.
